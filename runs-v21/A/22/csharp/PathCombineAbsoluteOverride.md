The endpoint accepts a user-supplied `file` query parameter and combines it with `_reportsRoot` using `Path.Combine()`. Because `Path.Combine()` discards the first argument when the second is an absolute path, an attacker can bypass the directory restriction by providing an absolute path like `C:\Windows\System32\config\sam`.

## Fix
### File: PathCombineAbsoluteOverride.cs

```csharp
using Microsoft.AspNetCore.Mvc;

namespace EvalCases.Controllers;

[ApiController]
[Route("api/[controller]")]
public class ReportsController : ControllerBase
{
    // Reports generated by the application are normally written here and
    // nowhere else; the intent is that this endpoint can only ever serve
    // files from this directory.
    private readonly string _reportsRoot = @"C:\App\Data\Reports";

    [HttpGet("export")]
    public IActionResult ExportReport([FromQuery] string file)
    {
        // Reject absolute paths to prevent directory escape
        if (Path.IsPathRooted(file))
        {
            return BadRequest("Invalid file path");
        }

        var reportPath = Path.Combine(_reportsRoot, file);
        var fullReportPath = Path.GetFullPath(reportPath);
        var fullRootPath = Path.GetFullPath(_reportsRoot);

        // Verify the resolved path remains within the reports directory
        var relativePath = Path.GetRelativePath(fullRootPath, fullReportPath);
        if (relativePath.StartsWith(".."))
        {
            return BadRequest("Access denied");
        }

        var reportText = System.IO.File.ReadAllText(fullReportPath);

        return Content(reportText, "text/plain");
    }
}
```

## Explanation
The fix implements two-layer path containment validation:

1. **Reject absolute paths**: `Path.IsPathRooted(file)` returns true for absolute paths like `C:\Windows\System32\config\sam`, preventing the `Path.Combine()` bypass that discards the root directory.

2. **Verify containment after canonicalization**: After combining and resolving both paths to their full canonical forms using `Path.GetFullPath()`, we check if the file path is within the root directory. `Path.GetRelativePath()` returns a path starting with `..` if the target is outside the base directory, allowing us to reject traversal attempts like `..\..\..\windows\config\sam`.

Together, these checks ensure that only files genuinely within `_reportsRoot` can be accessed.
